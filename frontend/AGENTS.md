# Frontend Instructions

Follow the repository-wide instructions in `../AGENTS.md`.

## Scope

These instructions apply to files inside `frontend/`.

## Frontend Rules

- Use Vue 3, TypeScript and Vite.
- Group application code by feature.
- Keep pages focused on orchestration.
- Use components for rendering.
- Use composables for reusable behaviour.
- Keep HTTP communication inside API clients.
- Use stores only for genuinely shared client state.
- Reuse existing components and patterns before creating new ones.
- Maintain strict TypeScript typing.
- Add or update tests for behavioural changes.
- Do not introduce new state-management or UI libraries without a demonstrated need.
