# Reborn

Reborn is a lightweight starter template for modern web applications.

Its goal is to provide a clean, maintainable and predictable foundation for both developers and AI coding assistants.

## Stack

### Backend

- Python 3.14
- FastAPI
- SQLModel
- Alembic
- uv

### Frontend

- Vue 3
- TypeScript
- Vite

## Getting Started

Install the project dependencies:

```bash
uv sync
```

Refer to the project documentation for the development workflow and available commands.
