# Creating a Project from Reborn

Before writing any application code:

## Repository

- Rename the project.
- Update README.md.
- Update AGENTS.md mission.
- Remove technologies that will not be used.
- Remove unused folders.
- Decide whether to use just, make or neither.
- Configure CI.
- Configure licensing.

## Backend

- Review dependencies.
- Remove unused modules.
- Configure database.

## Frontend

- Choose UI library (or none).
- Configure routing.
- Configure state management.

## Documentation

- Replace the mission.
- Add domain documentation.
- Remove template references.

When finished, delete this file.
